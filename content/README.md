# Content

Static content catalogue shipped with the build and imported by both the SPA and the Functions (TECH_SPEC 3, 4, 10).

Planned files: `units/*.json`, `modules.json`, `misconceptions.json`, `diagnostics.json`, `personas.json`, `schools.json`, `leader-demo.json`, `approved-sources.json`, `tags.json`.

Rules: every unit is drafted with `reviewedBy: null`; curriculum codes stay `AC9-TODO` / `NSW-TODO` until a human verifies them; no student data; all schools and people are fictional.
