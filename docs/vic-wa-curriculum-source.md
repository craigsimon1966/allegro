# Where the Victorian and WA curriculum lists come from

`content/curriculum/vic-maths.json` and `content/curriculum/wa-maths.json` were extracted on 27 Nov 2026 from the official Word documents. Both hosts block downloads from the cloud build machine, so the extraction ran in a browser on the official page and the result was compared, by SHA-256 of the compact JSON, with the file written into the repo. Both matched exactly.

## How each list was read

- Victoria: every content description is followed in the document by its code on its own line (for example `VC2M8A02`). The extractor took each code of the form `VC2M` + year (F, 1 to 10) + strand (N, A, M, SP, ST, P) + two digits, and the description line above it. Fractions written as Word equations became `1/2`. Levels A to D and 10A codes do not match that pattern, so they are left out.
- WA: each sub-strand ("Sub-strand: Algebraic techniques") is followed by a table whose header row names the years (Pre-primary, Year 1 ...). Each entry is one year column of one sub-strand, named "Year 8 Algebraic techniques" (Pre-primary is stored as year F). Within a cell, everything from a "Year 9 optional" or "Year 10 optional" marker onwards is left out. Superscripts in Word equations became `²` and `ˣ`. In `wa-maths.json` the cell's paragraphs are joined with "; ", and a paragraph that continues the one before it (it starts with a lower-case letter, as in "of the form" followed by "x²=k if k>0") is joined with a space.

Only the entries used by Allegro's units and topics (`curriculumRefs.vic` and `.wa` in content/units, `curriculum.vic` and `.wa` in content/tags.json) were kept. To add another, read it from the same document in the same way, and the unit tests will check that every code a unit or topic uses is in the list and belongs to its years.
