Worked example

Find the rule for this table

x0123
y1357
↳ +2 every time x goes up by 1
1
y goes up by 2 each step, so the rule starts with 2x.
2
When x = 0, y = 1 (the green box), so add 1.
3
y = 2x + 1
✓
Check: x = 3 gives 2 × 3 + 1 = 7.
In class: ask "what happens when x = 0?" before anyone guesses the rule.
