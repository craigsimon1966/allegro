A student says 2x means 2 + x. How do I explain it?
AI
Use numbers. Ask: if x = 5, is 2x equal to 7 or 10? Rewrite 2x as 2 × x so the hidden multiplication shows.
Then put 2x and x + 2 side by side for x = 0 to 4. They only match when x = 2.
