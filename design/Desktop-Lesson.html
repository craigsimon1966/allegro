Finding the rule from a table

AC v9 · to verify    NSW · to verify
watch

Watch for this error

Reviewed content
Students say: "y goes up by 2, so the rule is y = x + 2." Ask: "Test it with x = 3. Do you get 7?" They get 5, so they look again at what happens when x = 0.
20'

We do: guided practice · 15 min

AI DRAFT
Three tables on mini whiteboards. Students find the rule, then test it with the last column before showing.
Table A
x: 0, 1, 2, 3
y: 3, 5, 7, 9
y = 2x + 3
Table B
x: 0, 1, 2, 3
y: 1, 4, 7, 10
y = 3x + 1
Table C (stretch)
x: 1, 2, 3, 4
y: 6, 10, 14, 18
y = 4x + 2
Why this block works
Tables A and B start at x = 0, so the constant can be read straight off. Table C starts at x = 1, so students must work back to x = 0.
That's understanding, not pattern spotting.
Testing with the last column catches the "y = x + 2" error early.
