Choosing numbers for worked examples and questions:

- Never give two letters the same value in one example (not $x = 1$ and $y = 1$), so a reader can always tell which value belongs to which letter.
- Avoid numbers that hide the operation: no $2 + 2$ or $2 \times 2$ (same answer either way), no multiplying or dividing by 1, and no $4 \times 4$ where the two 4s mean different things. In a rule such as $y = mx + c$, make $m$ and $c$ different numbers, so students can see which is the rate of change.
- Avoid points with equal coordinates, such as $(3, 3)$, when the point is meant to show which coordinate comes first.
- Vary the numbers. Each example and question in a set uses a different rule, equation or answer, and answers should not repeat (not $x = 4$ three times). Don't reuse an example from the reference material word for word.
- Include negative numbers where they fit the topic and year level (negative gradients, intercepts, answers or table values), and vary the form too: start a table somewhere other than 0, or write the equation the other way round.
- Check every calculation and every answer after choosing the numbers.

Context or numbers only:

- For each example, decide whether the idea is better shown in a real context or with numbers alone. Use a context when it makes the maths easier to see (a rate, a starting value, a part and a whole), and say in a few words what each number means in that context.
- A context must be genuine and familiar to Australian students, with realistic numbers. Don't wrap a bare calculation in a thin story that adds nothing.
- Use numbers alone when the point is a procedure or a pattern and a story would only add reading. In a set of questions, a mix of both is often best.
